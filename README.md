# 星光彼岸（Starlit Horizon）

考研备考桌面应用（Windows）。本仓库**仅用于发布安装程序，不含任何源码**。

## 📥 下载安装

前往 **[Releases 页面](https://github.com/1Trent/starlit-horizon/releases)** 下载最新版本：

| 文件 | 说明 |
|---|---|
| `星光彼岸-Setup-*.exe` | 安装版（推荐）：双击安装到系统 |
| `星光彼岸-*-portable.exe` | 免安装版：单文件，下载后直接运行 |

系统要求：Windows 10 / 11（64 位）

## ✨ 主要功能

- 📐 **四科刷题**：数学 / 408 / 英语 / 政治 + 错题本 + 智能复习计划
- 🤖 **AI 智能助手**：34 个工具（学情诊断 / 择校 / 出题 / 讲题），支持联网搜索与本地知识库（RAG）引用
- 📚 **本地知识库**：导入文档（PDF / Word / Markdown），扫描件自动 OCR，AI 检索引用、对话中直接写入
- ✍️ **手写判题**：平板导出 / 数位板书写 → AI 多模态判题 + OCR 转写 + 原图留档
- 🔍 **OCR 识别**：图片 / PDF（整本分批、页码自选、点击预览）
- 📊 **学习统计**：学习日历、热力图、每日详情（做题 / 错题 / 背词 / 专注）
- 📡 **局域网联动**：手机手写板投屏、番茄钟同步、学习数据推送
- 🎯 **择校库 / 就业方向**：381 所院校分数线与专业数据
- 🎵 **学习氛围**：音乐播放、氛围主题、桌面小组件、星灯系统
